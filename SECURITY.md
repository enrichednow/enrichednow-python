# Security policy

## Reporting a vulnerability

Email **hello@enrichednow.com** with what you found and how to reproduce it. Please do not open a public issue
for a security problem.

We will confirm that we have your report, tell you what we find, and say when a fix is released.

## Supported versions

Fixes go into the latest release.

## API keys

Never put an API key in an issue, a pull request or a log you share. If a key has been exposed, revoke it in the
console under **API keys** and create a new one.
